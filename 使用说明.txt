BiliBox · B站视频下载工具
==================================================

【快速开始】
1. 把整个文件夹解压到任意位置（比如 D:\BiliBox）
2. 双击「启动 BiliBox.bat」
3. 窗口里会显示一个网址（如 http://127.0.0.1:8931/），
   正常情况下浏览器会自动打开；没有的话手动复制粘贴访问
4. 粘贴 B站 链接 → 点「解析」→ 勾选条目 → 选画质 →「开始下载」

不需要安装 Python，不需要装任何东西。整个文件夹就是程序本体。
想卸载：直接删掉这个文件夹即可（下载的视频记得先移走）。

【清晰度】

未登录 ................ 最高 720P
登录后 ................ 最高 1080P
大会员账号 ............ 4K / 杜比视界 / HDR / 1080P60

登录方式：点右上角「未登录」→ 用 B站 手机 App 扫码确认。
二维码 3 分钟有效，过期后窗口会自动换一张新的，不用手动刷新；
如果没登录就选了 1080P 及以上，点「开始下载」时会先问一句：
点「确定」按 720P 先下，点「取消」会自动弹出扫码窗口让你登录。
手机确认后稍等 1-2 秒，右上角变成你的昵称就说明登录成功了。
登录状态保存在程序目录的 config.json 里，只存在你自己电脑上。

注意：这里的「登录」指在本程序里扫码登录，和你在浏览器里登录 B站 是两回事。
浏览器登录不会共享给本程序，所以网页上看着是已登录状态，
本程序右上角仍会显示「未登录」，最高只能下 720P。
想下 1080P 及以上，必须在程序里单独扫一次码。

【合集怎么存】

收藏夹、UP主投稿里如果混着多分P视频或 UP主合集，
解析时会自动展开成一条条可单独勾选的条目，
下载时按来源自动分文件夹，例如：

  英语/                              ← 收藏夹名（最外层就是任务名）
    01 27考研英语作文模板.../        ← 合集：序号=它在收藏夹里的位置
      01 1.前言.mp4                  ← 集内序号 + 分集标题
      02 2.大纲解析及侧重点.mp4
    04 单个视频.mp4                  ← 独立单集，同样带收藏夹序号

这样同一层里 01、04、08 依次排下来，和收藏夹里的顺序完全一致，
合集是一层文件夹，单集是一个文件，一眼能看出哪些是成套的。

下载中想看里面每个文件？点任务卡上的「明细」：
  - 一行一个文件，显示它的状态、大小、进度
  - 还没下完的文件后面有「取消」，可以单独掐掉这一个
  - 点「收起」折叠回来
总进度是按每条视频的时长加权算的，长视频占的份额大，
所以整条进度条是一点点往前爬，不会下完一个小文件就猛跳一下。

下载目录和文件摆放
  设置里点「选择」会弹出 Windows 的文件夹选择框，选哪就存哪；
  旁边「打开」直接打开当前目录。
  文件整理方式有三档：
    平铺           视频、字幕、弹幕、封面并排放在一起（默认，只要视频时最清爽）
    每条一个文件夹  每个视频单独一个文件夹，四个文件都在里面，不会串
    按类型分目录    1 视频 / 2 字幕 / 3 弹幕 / 4 封面，一眼看出有哪些东西

断点续传（v2.0 新增）
  下载被打断（关程序、断网、电脑休眠）不用从头再来：
  下到一半的进度存在 data\cache 里，重新打开程序后，任务卡会显示「已中断」，
  点「继续下载」，已经下完的分片直接跳过，只补剩下的部分。
  实测：13MB 视频下到 6/7 片时强制结束进程，重开后 4.8 秒补完。

任务列表也不会丢了（v2.0 新增）
  关掉程序再开，之前的任务都在，能看到哪些完成了、哪些中断了。
  中断的那些点「继续下载」接着走。

收藏夹更新后只下新的（v2.0 新增）
  解析完，下过的条目会带绿色「已下载」角标，默认不勾选；
  列表栏有个「只选新增」，点一下自动只勾没下过的。

两个省心的小地方
  取消过的条目，点任务卡上的「重试」会重新排队下载，不会一直卡在取消状态；
  同一个收藏夹重复下时，已经下好的文件会直接跳过，不重复吃带宽。

==================================================
【下载的文件在哪】

默认：程序目录\downloads\
可以在设置里改成任意目录（比如 D:\Videos\B站）。

下载多条内容（合集、多P、UP主）时，会自动建一个子文件夹，
文件按「01 标题.mp4」的序号命名，方便排序。

【设置项说明】（右上角齿轮）

下载目录          想存哪就改哪
同时下载任务数     一次并行处理几个任务，默认 2
单文件并行线程     单个视频切成几段同时下，默认 8
                  B站 对单 IP 限速，调高到 16 有时能更快
代理              需要走代理时填，例如 http://127.0.0.1:7890
Cookie            一般不用手填，扫码登录更方便

【常见问题】

Q：提示「取流失败，可能需要登录」
A：这个视频的高清源需要登录才能拿到。点右上角扫码登录后重试。

Q：速度只有几百 KB/s
A：B站 对单个连接有速度限制。把「单文件并行线程」调到 16，
   或减少「同时下载任务数」，通常能跑满带宽。

Q：杀毒软件报毒 / 拦截
A：包里带的是官方 Python 运行时和 ffmpeg，属于常见的绿色软件误报。
   所有程序逻辑都是明文 .py 文件，可以直接打开看。可以加入信任。

Q：下载到一半失败了
A：在任务卡片上点「重试」，会只补下失败的条目，已完成的不会重下。

Q：关掉黑色窗口后网页就打不开了
A：那个窗口就是程序本体，关掉等于退出。重新双击 bat 即可。

Q：双击 bat 一闪而过
A：多半是没有完整解压（缺少 runtime\python\python.exe）。
   请用解压软件完整解压，不要只把 bat 拖出来单独运行。

Q：显示「缺少 ffmpeg」
A：检查 runtime\ffmpeg.exe 是否存在。缺了它视频能下但不能合并音轨。
