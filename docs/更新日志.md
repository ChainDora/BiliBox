# 更新日志

按版本倒序列出变更。每个版本都对应一个可运行的分发包。

---

## v2.0 · 产品化三件事

**新增**

- 断点续传：分片级缓存 + manifest，中断后从断点继续
- 任务持久化：`data/tasks.json`，重启不丢历史
- 增量下载：已下载标记、默认只勾新增、"只选新增"按钮
- 新增模块 `records.py`（下载记录与缓存管理）

**变更**

- 缓存目录从 `downloads/.bilibox_tmp` 改为 `data/cache/<hash>`，稳定不随任务变化
- 版本号 `APP_VER` 改为 `2.0`

**修复**

- 缓存目录名带 `:` 时 `os.path.normpath` 误判
- 下载失败返回 `None` 导致目录树显示 4 个文件实际只下 2 个
- 任务完成不落盘，重启后误判为"已中断"

**实测**

- 13MB 视频 7 片，强杀后重启 4.82 秒补完
- 253 条收藏夹：已选 252 / 253
- 包体 47.7MB，47 文件

## v1.9 · 代码审查

**修复（6 个真实 bug）**

1. 取消过的条目重试永远复活不了 — `_api_retry` 没重置 item 的 `_token`
2. 单流下载失败被当成功 — `_download_single` 返回值未被检查，错误被 ffmpeg 报错掩盖
3. 重试后总进度翻倍 — `rewind()` 未清 `total`
4. 分片线程数失控 — "一片一线程"，100MB 切 17 线程
5. 超长标题写盘失败 — 按字符截断，中文字节超 255
6. 字幕时间戳可能为 1000ms — 浮点取整溢出

**优化**

- 已存在文件跳过（重复下载 3.0s → 0.9s）
- 未登录画质封顶 720P，省 3~4 次无效请求
